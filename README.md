# Michael Alejo - Portfolio

A modern, responsive portfolio website showcasing my work as an AI/ML Engineer.

## 🚀 Built With

- **Next.js 16** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Lucide React** - Icons

## ✨ Features

- Responsive design for all devices
- Dark mode support
- Smooth scroll animations
- SEO optimized with Open Graph tags
- Dynamic OG image generation
- Avatar component with photo/initials fallback
- Conditional CTA buttons on project cards

## 📁 Project Structure

portfolio/
├── app/                   # Next.js app directory
├── components/           # React components
└── lib/                  # Data and types

## 🛠️ Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📝 Customization

### Add Your Profile Photo
- Add `public/avatar.jpg` or `public/avatar.png`

### Add Your CV
- Add `public/cv.pdf`

### Update Data
Edit files in `lib/data/`

## 🚢 Deploy to Vercel

1. Push to GitHub
2. Import on Vercel
3. Deploy!
